🔄 KinAura Update System

How admin changes propagate to user devices

⚡ Immediate Updates (Real-time)

These changes appear instantly for users:

  • ✅ New treatments/services added in admin panel
  • ✅ New pictures/images uploaded to gallery
  • ✅ Service descriptions, pricing changes
  • ✅ Appointment availability updates
  • ✅ User booking confirmations
  • ✅ Admin-to-patient notifications

Why immediate? This data comes directly from your backend API in real-time.

🔄 Cached Updates (10-15 minutes delay)

These changes may take up to 15 minutes:

  • 🔄 Service metadata changes (if cached)
  • 🔄 Large image galleries (if heavily cached)
  • 🔄 App interface improvements

Cache Strategy: React Query caches data for performance, then auto-refreshes when stale.

📱 User Experience Timeline:

Admin adds new treatment at 2:00 PM
→ 2:00 PM: Change saved to database
→ 2:00 PM: Users opening app see new treatment immediately
→ 2:00-2:15 PM: Users with cached data see update within 15 minutes
→ 2:00 PM+: All new visitors see change immediately
// Your app's caching strategy: useServices({ staleTime: 10 * 60 * 1000, // 10 minutes refetchOnWindowFocus: true, // Updates when user returns refetchOnReconnect: true, // Updates when back online }); // Result: Fresh data every 10 minutes + smart updates

🚀 Update Triggers for Users:

App Launch

When users open the PWA, fresh data is automatically fetched from your backend API.

Page Navigation

Moving between sections (Services → Gallery → Bookings) triggers data refreshes.

Background Refresh

App automatically checks for updates every 10-15 minutes when active.

Network Reconnect

When device reconnects to internet, app immediately syncs latest changes.

📱 Future: Native App Updates

If you deploy as native mobile app (iOS/Android):

  • ✅ Content updates (treatments, images) - Still immediate
  • 🔄 App features (new pages, buttons) - Require app store update
  • 🔄 Design changes - Require app store update

Hybrid approach: Content via API (immediate) + App features via store updates (1-7 days approval)
