- Create Apple Developer Account ($99/year)

### **2. Codemagic Configuration** (15 minutes)  
- Connect GitHub repository to Codemagic
- Add environment variables from `.env.mobile.template`
- Upload iOS code signing certificate
- Upload Android keystore for signing

### **3. Store Listings** (30 minutes)
- Create app in App Store Connect using templates
- Create app in Google Play Console using templates  
- Upload app icons and screenshots
- Configure privacy policy and support URLs

### **4. First Build** (20 minutes)
- Trigger iOS development build in Codemagic
- Trigger Android development build in Codemagic
- Download and test on physical devices
- Verify all features work correctly

### **5. Store Submission** (10 minutes)

- Upload Android AAB to Play Console (2-4 hours review)
- Monitor review status and respond to feedback
